# Implementation Plan: Color Palette Cleanup

**Branch**: `004-color-palette-cleanup` | **Date**: 2026-02-25 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/004-color-palette-cleanup/spec.md`

## Summary

Consolidar a paleta de cores do site de ~30 variáveis CSS (com duplicatas e subdivisões excessivas) para uma estrutura limpa em duas camadas: (1) **paleta base** com 11 cores nomeadas descritivamente, e (2) **aliases semânticos mínimos** do shadcn/ui (background, foreground, primary, secondary, destructive, muted, accent, border, ring, card, popover) que apontam para as cores da paleta base. Remover todas as subdivisões desnecessárias (chart-*, sidebar-*, duplicatas como burgundy/gold separados do primary/accent).

### Camada 2: Aliases Semânticos shadcn/ui (mínimos)

Definidas em `:root` apontando para a paleta base. Mantidas porque shadcn/ui depende delas nos componentes (button, badge, input, etc.).

| Alias Semântico | Aponta Para | Notas |
|----------------|-------------|-------|
| `--background` | `--parchment` | Fundo global |
| `--foreground` | `--carbon-black` | Texto global |
| `--primary` | `--night-bordeaux-2` | Botões, links, badges default |
| `--primary-foreground` | `--parchment` | Texto sobre primary |
| `--secondary` | `--dust-grey` | Backgrounds secundários |
| `--secondary-foreground` | `--carbon-black` | Texto sobre secondary |
| `--muted` | `--powder-petal` | Backgrounds atenuados |
| `--muted-foreground` | `--coffee-bean` | Texto metadata |
| `--accent` | `--toffee-brown` | Hover/accent |
| `--accent-foreground` | `--carbon-black` | Texto sobre accent |
| `--destructive` | `--scarlet-red` | Erros |
| `--destructive-foreground` | `--parchment` | Texto sobre erro |
| `--card` | `--parchment` | Fundo de cards |
| `--card-foreground` | `--carbon-black` | Texto em cards |
| `--popover` | `--parchment` | Fundo de popovers |
| `--popover-foreground` | `--carbon-black` | Texto em popovers |
| `--border` | `--dust-grey` | Bordas |
| `--input` | `--dust-grey` | Input borders |
| `--ring` | `--night-bordeaux` | Focus ring |

**Removidos** (não usados ou subdivisões desnecessárias):
- `--chart-1..5` (não utilizado)
- `--sidebar-*` (não utilizado)
- `--burgundy`, `--burgundy-dark`, `--burgundy-hover`, `--burgundy-accent` (duplicatas de primary — usar paleta base diretamente)
- `--gold`, `--gold-light`, `--gold-hover` (duplicatas de accent — usar paleta base diretamente)
- `--accent-gold`, `--accent-rose`, `--accent-beige` (subdivisões excessivas)
- `--rose`, `--beige`, `--gray-light`, `--white`, `--gray`, `--black` (usar paleta base diretamente)

### Tailwind Class Migration (Old Custom → New)

Componentes que usavam cores custom (não semânticas) migram para os nomes da paleta base:

| Classe Antiga | Nova Classe |
|---------------|-------------|
| `bg-burgundy` | `bg-night-bordeaux-2` |
| `bg-burgundy-dark` | `bg-rich-mahogany` |
| `text-burgundy` | `text-night-bordeaux-2` |
| `text-burgundy-dark` | `text-rich-mahogany` |
| `bg-gold` | `bg-toffee-brown` |
| `bg-gold-light` | `bg-olive-wood` |
| `bg-gold-hover` | `bg-olive-wood` |
| `text-gold` | `text-toffee-brown` |
| `bg-rose` | `bg-powder-petal` |
| `text-rose` | `text-powder-petal` |
| `bg-beige` | `bg-dust-grey` |
| `bg-gray-light` | `bg-dust-grey` |

Classes semânticas shadcn/ui (`bg-primary`, `text-foreground`, `bg-muted`, `border-border`, etc.) **permanecem como estão** — apenas o valor CSS por trás delas muda.
